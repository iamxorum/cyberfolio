# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead:
**Security > Report a vulnerability** on this repository.

Include the affected route or file, the steps to reproduce, and the impact you expect. You can expect a first reply within a few days.

## Scope

In scope: the code in this repository, including the Turnstile gate and access cookie, the CSP, rate limiting, and the private file routes.

Out of scope: third-party services (Cloudflare, Strava, Steam, Umami) and any deployment you host yourself.

## Supported versions

Only the latest release receives fixes.
