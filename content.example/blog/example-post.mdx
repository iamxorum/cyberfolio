## Headings, lists, code

Regular Markdown works:

- A bullet point
- Another one

```ts
// Fenced code blocks are supported
const hello = "world";
```

> A blockquote, for pulling out a quote or a note.

Links work too ... [internal links](/projects) resolve with Next's router, external links open in a new tab automatically.

## Tables and more

GitHub-style tables, strikethrough and task lists work:

| Feature | Supported |
| --- | --- |
| Tables | yes |
| ~~Strikethrough~~ | yes |

Images open full size when clicked, and their alt text is shown as the caption. Add `series: "Name"` to the frontmatter to group posts into a numbered series, and `updated: "2026-02-01"` to show an "updated" date.

## Callouts and code labels

A quote that starts with `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` or `[!CAUTION]` becomes a labelled callout:

> [!WARNING]
> Check the rule order before you reload the firewall.
